# AdsMind — Concept Validation Landing Page

A lightweight static landing page for validating interest in AdsMind without exposing detailed product logic or implementation flow.

## Files

- `index.html` — landing page
- `styles.css` — responsive styling
- `script.js` — preview CTA interaction

## Deploy to GitHub Pages

1. Create a new GitHub repository, e.g. `adsmind`.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

## Before public validation

The current CTA only records interest visually in the browser. Connect an analytics tool before publishing if you want to measure real CTA clicks.
